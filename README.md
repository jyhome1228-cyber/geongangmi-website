# 건강미 홈페이지

건강미 공식 홈페이지의 기존 웹 프로토타입과 Cafe24 재구축 작업을 함께 관리하는 저장소입니다.

## 현재 상태

### Legacy prototype
루트의 기존 HTML/CSS/JS는 2026년 7~8월에 제작한 1차 프로토타입입니다.

- 건강미 소개
- 프로그램
- 변화 기록
- 건강미 저널
- 건강미 샵
- 지점 안내 / 예약

기존 화면과 콘텐츠를 확인하기 위한 참고 구현으로 유지합니다.

### Cafe24 rebuild
새 공식 홈페이지는 `cafe24/` 디렉터리에서 재구축합니다.

- 디자인 토큰 단일화
- 공통 레이아웃 / 컴포넌트 정리
- 모바일 반응형 재정비
- 브랜드 페이지와 Cafe24 커머스 모듈 분리
- 콘텐츠 원본 데이터 정리
- 기존 누적 CSS(v5~v22) 의존 제거

자세한 구조는 [`cafe24/README.md`](./cafe24/README.md)를 참고하세요.

## 로컬 실행

기존 프로토타입:

```bash
npm install
npm run dev
```

Cafe24 리빌드 프리뷰:

```text
/cafe24/preview/index.html
```

Vite 개발 서버에서 위 경로를 열어 확인할 수 있습니다.

## 작업 원칙

1. 기존 프로토타입을 바로 삭제하지 않습니다.
2. 신규 화면은 `cafe24/` 구조에서 먼저 완성합니다.
3. 검수된 코드만 Cafe24 스마트디자인 스킨으로 이식합니다.
4. 상품/주문/회원 기능은 Cafe24 기본 모듈을 유지합니다.
5. 브랜드 소개/프로그램/지점/저널 영역은 건강미 디자인 시스템으로 통일합니다.
